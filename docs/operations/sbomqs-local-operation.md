# Локальна перевірка якості SBOM через sbomqs

`sbomqs` є додатковою локальною перевіркою якості створеного PAO CycloneDX SBOM.
Її оцінка лише допомагає ручному перегляду. Вона не підтверджує безпеку, ліцензії,
відповідність вимогам або готовність релізу.

## Стандартний безпечний стан

За відсутності схваленого інструмента PAO створює для `sbomqs` явний статус
`UNAVAILABLE`. Це очікувана поведінка: аудит не завантажує інструмент, не шукає його
в мережі й не підміняє відсутню оцінку нулем або позитивним висновком.

## Підготовка лише після окремого рішення власника

У v0.3 інструмент входить до профілю підготовки `mvp`. Запустіть із перевіреного
архіву звичайний `pao setup --root <installation-root> --profile mvp`, перегляньте
план і повторіть із `--apply --target <synthetic-target>`. Точні команди для обох
ОС наведені в [початковій інструкції](../public-start.uk.md).

Майстер перевіряє джерело, ліцензію, версію та SHA-256, проводить синтетичні
проби й показує остаточний інвентар для рішення власника. Після точного
підтвердження він створює каталог інструментів, runtime approval і нову
конфігурацію v3. Без підтвердження залишаються чернетки `UNAPPROVED`.
Погодження чинне щонайбільше 30 днів; коротші строки ресурсів також перевіряються.
Ручний файл `approved-tool.json` належить до попереднього формату й не є шляхом
активації v3. Зміна погоджених ресурсів потребує нового перегляду.

## Межі запуску

Після проходження цих умов PAO запускає лише фіксовану команду
`sbomqs score <captured-cyclonedx> --legacy --json` у контейнері без мережі. Версія
2.1.1 потребує `--legacy`, оскільки її новий JSON не має сумісного поля `avg_score`.
Цільовий проєкт
не монтується для запису й не виконується. `sbomqs` отримує тільки незмінний
CycloneDX-доказ, створений тим самим запуском Syft; первинний результат і зв'язок
двох доказів залишаються у приватному сховищі.

Контейнер отримує лише сам файл SBOM, без сусідніх первинних результатів; папка
цільового проєкту для sbomqs не монтується. Оцінка відхиляється, якщо запис запуску
невалідний, Syft не пройшов перевірку походження, або результат sbomqs обрізаний чи
неповний. Поточні межі підтримки наведено в
[описі продукту](../release/v0.3-public-scope.md).

Перед першим реальним застосуванням потрібен запис власника про security/license
review саме цього файла та цієї конфігурації. Без нього не використовуйте показник
як підставу для жодного рішення.
